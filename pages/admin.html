จัดการข้อมูลเว็บไซต์ Content Manager

เพิ่ม แก้ไข และลบข่าวสารประจำจังหวัด ข้อมูลท่องเที่ยว และของดีจังหวัด — การเปลี่ยนแปลงที่นี่จะ แสดงผลจริงบนหน้าเว็บไซต์ (หน้าแรก, ข่าวสาร, ท่องเที่ยว, รายละเอียดสินค้า) ทันทีที่บันทึก

หมายเหตุการใช้งาน: ข้อมูลในหน้านี้บันทึกลง แหล่งข้อมูลกลางจริงของเว็บไซต์ (GitHub Repository) ผ่าน Secure API — เมื่อบันทึกสำเร็จ ผู้ใช้ทุกคนจากทุกเครื่อง/เบราว์เซอร์จะเห็นข้อมูลเดียวกัน (อาจใช้เวลาสักครู่ให้ GitHub Pages อัปเดตเว็บไซต์หลังบันทึก)
