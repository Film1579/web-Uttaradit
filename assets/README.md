# assets/

โฟลเดอร์นี้ยังไม่มีไฟล์ภาพจริง เนื่องจากไฟล์ต้นทางที่ใช้รวมเว็บไซต์นี้ (project_code, AETHER)
ไม่มีไฟล์รูปภาพแนบมาด้วย — มีเฉพาะโค้ดโครงสร้าง/เนื้อหา

เว็บไซต์นี้ยังใช้งานได้ตามปกติแม้ไม่มีรูปภาพจริงสักไฟล์เดียว เพราะมี **procedural fallback**
(`js/img-fallback.js`) คอยแทนที่ `<img>` ที่โหลดไม่สำเร็จด้วยภาพ SVG โทนเขียว–ทองของจังหวัดโดยอัตโนมัติ
แนวคิดนี้ยืมมาจาก AETHER (aether-launch/assets/README.md เดิม)

เมื่อมีไฟล์ภาพจริง ให้วางตามตารางนี้แล้วไม่ต้องแก้โค้ดที่อื่นเพิ่มเติม:

| ตำแหน่งใช้งาน | ที่อ้างอิงใน config.js / HTML | ขนาดแนะนำ |
|---|---|---|
| โลโก้/ตราจังหวัด | `assets/img/logo.png` | 96×96 (พื้นหลังโปร่งใส) |
| ภาพหน้าปก Hero (สไลด์ 3 ภาพ) | `CONFIG.hero[i].img` → `assets/img/hero-1.jpg` .. `hero-3.jpg` | ≥ 1920×1080 |
| ภาพประกอบ "แนะนำจังหวัด" | `assets/img/hero-2.jpg` (ใช้ซ้ำจากชุด Hero ได้) | ≥ 1200×900 |
| ภาพข่าวปกแต่ละข่าว | `CONFIG.news[i].img` → `assets/img/n1.jpg` .. `n9.jpg` | 1200×750 (4:2.5) |
| ภาพสถานที่ท่องเที่ยว | `CONFIG.travel[i].img` → `assets/img/t1.jpg` .. `t5.jpg` | 1200×900 (4:3) |
| Social preview (og:image) | `assets/img/og.jpg` | 1200×630 |
| ไอคอนเว็บแอป (PWA) | `assets/icons/icon-192.png`, `icon-512.png`, `maskable-512.png` | ตามชื่อไฟล์ |

ไฟล์ `favicon.svg` ในโฟลเดอร์นี้ใช้เป็น favicon ชั่วคราว (โทนเขียว–ทองของจังหวัด)
สามารถแทนที่ด้วยตราประจำจังหวัดอุตรดิตถ์จริงได้ทันทีที่มีไฟล์

**หมายเหตุเรื่องไอคอน PWA:** เนื่องจากไฟล์ `icon-192.png` / `icon-512.png` / `maskable-512.png`
ยังไม่มีอยู่จริง จึงถูกนำออกจากรายการ `icons` ใน `manifest.webmanifest` ชั่วคราว (เหลือเฉพาะ
`favicon.svg` ที่มีไฟล์จริง) เพื่อไม่ให้เบราว์เซอร์พยายามโหลดไฟล์ที่ไม่มีอยู่ เมื่อเพิ่มไฟล์ไอคอนจริง
ตามตารางด้านบนแล้ว ให้เพิ่มรายการกลับเข้าไปใน `manifest.webmanifest` ด้วย
